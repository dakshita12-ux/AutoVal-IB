Standalone Python DCF Script (`dcf_engine.py`) 

import yfinance as yf
import pandas as pd

def run_ib_dcf(ticker, rf=0.071, erp=0.055, tg=0.04):
    """
    Investment Banking Standard DCF Valuation Engine
    """
    stock = yf.Ticker(ticker)
    info = stock.info
    
    # 1. Extract CAPM Inputs
    beta = info.get('beta', 1.0)
    ke = rf + (beta * erp)
    kd = 0.08  # Pre-tax cost of debt estimate
    tax_rate = 0.25
    
    market_cap = info.get('marketCap', 1)
    total_debt = info.get('totalDebt', 0)
    wacc = (market_cap / (market_cap + total_debt)) * ke + \
           (total_debt / (market_cap + total_debt)) * kd * (1 - tax_rate)
           
    # 2. Free Cash Flow Projections
    fcf_base = info.get('freeCashflow', 425000000000)
    cagr = 0.125
    fcf_proj = [fcf_base * ((1 + cagr) ** i) for i in range(1, 6)]
    
    # 3. Present Value & Terminal Value
    pv_fcfs = sum([fcf / ((1 + wacc) ** i) for i, fcf in enumerate(fcf_proj, 1)])
    tv = (fcf_proj[-1] * (1 + tg)) / (wacc - tg)
    pv_tv = tv / ((1 + wacc) ** 5)
    
    ev = pv_fcfs + pv_tv
    eq_val = ev - total_debt
    implied_price = eq_val / info.get('sharesOutstanding', 1)
    
    return {"Enterprise_Value": ev, "Equity_Value": eq_val, "Implied_Price": implied_price, "WACC": wacc}

# AutoVal-IB: Investment Banking Valuation & M&A Pitchbook Engine ## 📌 Overview **AutoVal-IB** is an automated corporate valuation and transaction advisory dashboard built for Investment Banking analysts. It automates 3-Statement financial data extraction, executes a 3-Stage Discounted Cash Flow (DCF) model, constructs multi-variable valuation sensitivity matrices, performs Trading Comps peer benchmarking, and models M&A Accretion/Dilution deal mechanics. Designed to align with corporate finance standards used across Global Investment Banking divisions (e.g., Bank of America, Goldman Sachs, J.P. Morgan). --- ## 🛠️ Key Capabilities & Technical Features - **Discounted Cash Flow (DCF) Valuation:** - Automated CAPM engine calculating Cost of Equity ($K_e$), Cost of Debt ($K_d$), and tax-shielded Weighted Average Cost of Capital (WACC). - 5-Year Unlevered Free Cash Flow (FCFF) forecast model. - Dual Terminal Value estimation (Perpetual Growth Rate & Exit Multiples). - 2D Sensitivity Matrix assessing intrinsic share price sensitivity across WACC vs Terminal Growth rates. - **Comparable Company Analysis (Trading Comps):** - Peer group valuation benchmarking calculating $EV/EBITDA$, $P/E$, and $EV/Revenue$ multiples. - Automated statistical summary (Mean, Median, High, Low) for valuation positioning. - **M&A Accretion / Dilution Model:** - Strategic transaction structuring evaluating Cash vs. Equity consideration mixes. - Pro-forma combined net income and EPS reconciliation bridge factoring after-tax interest expense and synergetic cost savings. --- ## 🚀 Installation & Local Setup ```bash # Clone repository git clone https://github.com/YOUR_USERNAME/AutoVal-IB.git cd AutoVal-IB # Install Python dependencies pip install -r requirements.txt # Run Python Engine python dcf_engine.py ```
